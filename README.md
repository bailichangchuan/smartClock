# SmartClock 智能时钟系统

A smart clock based on ESP32 which can show your time, environment situation, and a small light

> **说明**: 本项目是在另一个分支中的已有代码基础上，由开发者指导AI助手进行系统性重构和优化的智能时钟系统。程序逻辑和运行逻辑由人工设计，AI负责具体实现和代码优化。本文档由AI生成。

## 🎯 项目概述

SmartClock是一个基于ESP32-C6的MicroPython智能时钟系统，采用**双核心并行处理架构**，具备环境监测、人体检测、音乐播放等智能功能。系统设计注重**非阻塞、模块化、易维护**，为用户提供流畅的智能时钟体验。

## 🏗️ 系统架构

### 双核心设计理念

| 核心 | 子系统 | 职责 | 运行特点 |
|------|--------|------|----------|
| **核心0** | 屏幕控制子系统 | 用户界面管理、串口屏通信 | 独占核心，确保UI流畅 |
| **核心1** | 定时器控制子系统 | 后台任务调度、智能功能 | 所有后台任务和持续性服务 |

### 核心架构特点

1. **main.py只在开机运行一次**：初始化硬件后启动两个子系统，然后结束
2. **明确的职责划分**：
   - 核心0：只处理UI相关功能
   - 核心1：处理所有后台任务和智能功能
3. **线程管理原则**：
   - 临时线程：一次性任务，执行完自动关闭
   - 持续性服务：长期运行的功能（人体检测、环境光检测等）
   - 线程归属：哪个子系统调用，线程就在哪个核心运行
4. **非阻塞设计**：所有功能模块都采用非阻塞设计，防止时序冲突

## 🔧 硬件要求

### 主要组件
- **主控板**: ESP32-C6
- **显示屏**: 串口屏（UART通信）
- **传感器**: 
  - 人体红外传感器 (SR602)
  - 环境光传感器 (TEMT6000) 
  - 温湿度传感器等
- **音频**: DFPlayer Mini MP3模块
- **网络**: WiFi连接（2.4GHz）

### 引脚配置

```python

# 传感器

# 音乐播放器

```

## 🚀 快速开始

### 1. 硬件连接
按照引脚配置连接所有硬件组件：

- 传感器 → 对应GPIO引脚

1. 将项目文件上传到ESP32-C6

3. 重启设备

系统启动流程：
```
1. 硬件初始化（网络、屏幕、传感器）
2. 启动核心1定时器子系统（后台线程）
3. 启动核心0屏幕子系统（主线程阻塞）
4. main.py结束，双核心并行运行
```
